# Travel Survey Template Guide
Master workbook is the default active dataset. Do not require new uploads for ordinary questions.
Q10 = budget change; Q11 = budget reduction actions; Q14 = likely airline; Q16 = airline considerations; Q19 = accommodation; Q21 = hotel brand; Q21a = hotel recommendation.
Country = QS0; region cluster = QHIDCLUSTER; age = QHIDAGE; budget segment = Segment_Budget; age segment = Segment_Age.
For multi-select questions, count Yes per option and use the eligible base. For a requested filter, filter respondent rows BEFORE counting. Never treat total sample as filtered base.
Do not infer changed choices from general considerations. Weighted statistics require validated weight field. Protect respondent IDs.
